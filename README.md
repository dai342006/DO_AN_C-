# DO_AN_C-
# 📚 DSA Practice – C++ / Python

Repository này chứa các bài tập **Data Structures & Algorithms (DSA)** mà mình luyện tập trong quá trình học lập trình.

## 🚀 Nội dung

Các bài tập bao gồm:

* Mảng (Array)
* Chuỗi (String)
* Cây nhị phân (Binary Tree)
* Đệ quy (Recursion)
* Thuật toán cơ bản
* Một số bài LeetCode

## 📂 Ngôn ngữ sử dụng

* C++
* Python

## 📑 Ví dụ một số bài

* Remove Duplicate from Array
* Climbing Stairs
* Binary Search Insert Position
* Valid Anagram
* Same Tree
* Symmetric Tree

## 🎯 Mục tiêu

* Luyện tư duy thuật toán
* Hiểu rõ cấu trúc dữ liệu
* Chuẩn bị cho phỏng vấn lập trình
